# Content Refresh

1. **Find candidates:** pages with falling clicks/impressions (compare periods in Search Console), positions 4-20, outdated facts, or lost AI citations.
2. **Diagnose why:** intent shifted, competitors improved, content outdated, cannibalization, technical issue, or lost links.
3. **Decide:** update, merge (301 redirect weaker page into stronger), rewrite, or retire.
4. **Update:** refresh facts and sources, add answer-first summary, new sections for missing subtopics, better examples, new visuals, updated FAQ, fix internal links, update the visible "last updated" date only when real changes were made.
5. **Republish and request indexing** where appropriate; log the change and date.
6. **Review after 4-8 weeks.**

Output: prioritized refresh list with diagnosis, action and expected impact.
