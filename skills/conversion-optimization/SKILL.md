# Conversion Optimization (CRO)

1. Match the page promise to the query and the ad/snippet that brought the visitor.
2. Above the fold: clear headline, who it is for, main benefit, one primary CTA.
3. Add proof near the CTA: testimonials, logos, numbers, case studies (real ones only).
4. Reduce friction: shorter forms, clear next step, fast load, mobile-friendly buttons.
5. Match CTA to funnel stage (guide download for early readers, demo or quote for ready buyers).
6. Add secondary paths: related content, newsletter, contact.
7. Track events and run one test at a time with a clear hypothesis.

Output: prioritized fix list per page with the hypothesis behind each.
