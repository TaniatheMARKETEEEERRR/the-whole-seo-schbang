# Link Building and Digital PR

## Tactics (white-hat)
- **Linkable assets:** original research, free tools, templates, definitive guides, data studies.
- **Digital PR:** newsworthy angles, expert commentary, journalist requests (e.g. HARO-style services, Qwoted, Featured).
- **Guest contributions** only on relevant, quality sites, offering real value.
- **Unlinked mentions:** find and politely request links.
- **Broken link and resource page outreach.**
- **Partnerships, podcasts, events, testimonials, local sponsorships.**
- Directories and profiles that are genuinely relevant.

## Avoid
Buying links, link farms, PBNs, mass irrelevant guest posts, over-optimized anchors. These risk penalties.

## Outreach email rules
Personalize the first line, be brief (under 120 words), state the value to *them*, one clear ask, polite follow-up after 4-5 days, max two follow-ups.

Output: target list (site, relevance, contact, angle) and 3 email variants.
