# Meta Titles and Descriptions

For each page provide 3 options:
- **Title** about 50-60 chars: primary keyword + distinct benefit or modifier (year only if truly time-sensitive, brand last).
- **Description** about 120-155 chars: what the reader gets, one proof or differentiator, soft call to action.
- Match intent. Do not promise what the page does not deliver.
- Every title and description unique across the site.

Output as a table: URL | Current | Option A | Option B | Option C | Character counts. Note that Google may rewrite snippets, so make the page content itself clear too.
