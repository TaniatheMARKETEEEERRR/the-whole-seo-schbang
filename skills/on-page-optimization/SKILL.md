# On-Page Optimization Checklist

- Title tag: unique, about 50-60 characters, keyword early, compelling.
- Meta description: about 120-155 characters, benefit plus reason to click.
- URL: short, readable, lowercase, hyphens.
- One H1 matching the page promise; logical H2/H3 hierarchy.
- Answer to the main query appears near the top.
- Keyword and variants used naturally in intro, headings and body.
- Images: compressed, descriptive file names, useful alt text, width/height set.
- Internal links: 3-8 relevant, descriptive anchor text; inbound links from related pages.
- External links to credible sources where helpful.
- Author, date published/updated, and sources visible.
- Schema added if suitable (see `schema-markup`).
- Mobile readability, no intrusive popups, fast loading main content.
- Canonical tag correct; page indexable.

Score each item Pass / Fix / Missing with the exact change to make.
