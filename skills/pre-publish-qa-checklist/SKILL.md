# Pre-Publish QA Checklist

Score each as Pass / Fix. Content publishes only when all critical items pass.

**Strategy:** matches search intent and the Goal Brief; one clear primary keyword; not cannibalizing an existing page.
**Content:** answers the question in the first lines; original value included; no padding; reading level fits the audience.
**Facts:** every claim sourced; no invented stats or quotes (`fact-checking`).
**E-E-A-T:** named author with bio, first-hand experience, credible sources, transparent business info (`eeat-content-quality`).
**Voice:** passes the humanizer edit and brand voice review.
**On-page:** title, meta description, URL, H1/H2s, image alt text, internal links (`on-page-optimization`).
**AEO/GEO:** answer-first blocks, FAQ, quotable passages, entity consistency.
**Technical:** indexable, canonical correct, mobile friendly, fast, schema valid.
**Conversion:** one clear CTA, tracking set up.
**Compliance:** disclosures for ads, affiliates or AI assistance where required; claims legally safe.

Output: scorecard, blockers, and a Go / No-Go decision.
