# Programmatic SEO

1. Validate demand: a repeatable query pattern with real searches (e.g. "[tool] alternatives", "[service] in [city]").
2. Ensure each page has **unique, useful data**, not just swapped keywords. Thin or duplicate pages risk being ignored or demoted.
3. Design the template: unique intro logic, data tables, FAQs, proof, internal links, schema.
4. Start with 10-20 pages, check indexing and engagement, then scale.
5. Set quality thresholds: pages without enough unique data are not published.
6. Maintain: refresh data, prune weak pages, monitor index coverage.

Output: pattern list, template wireframe, data sources, launch and quality plan.
