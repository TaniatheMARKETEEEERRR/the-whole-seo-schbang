# Search Intent Mapping

1. Search the query (or review SERP data). Note: page types ranking (guides, product pages, lists, tools, videos), SERP features (AI overview, featured snippet, PAA, local pack, shopping), and the freshness of results.
2. Label intent: informational, commercial investigation, transactional, navigational, or local. Note mixed intent.
3. Define the "job to be done": what must the reader walk away knowing or able to do?
4. Decide the best format: how-to, comparison, listicle, landing page, tool, glossary, case study, category page.
5. List must-have elements that top results share and **gaps** none of them cover (your angle).

## Output
Query | Intent | Winning format | Must-have sections | Gap/opportunity | Recommended page.
If your planned page type does not match the intent Google rewards, say so and recommend the right format.
