# Topical Authority Map

1. Pick 3-6 **pillar topics** that match what the business sells and what customers need to learn.
2. For each pillar, list **cluster pages**: definitions, how-tos, comparisons, use cases, mistakes, tools, templates, case studies, FAQs.
3. Mark each page: intent, target keyword, funnel stage, priority, status (new/update).
4. Define internal linking: cluster pages link up to the pillar, pillar links down to every cluster page, related clusters link sideways.
5. Cover the topic **completely** before expanding to new ones. Depth beats breadth.

## Output
Indented outline or table per pillar, then a recommended publishing order (foundation pages and revenue-closest pages first).
